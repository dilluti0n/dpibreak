  release

## Test

Build the Docker image once:

```bash
docker build -t dpibreak-aur contrib/aur/
```

Test a package:

```bash
docker run -it --rm dpibreak-aur bash
git clone https://aur.archlinux.org/dpibreak-git.git
cd dpibreak-git && makepkg -si
```

## Update PKGBUILD

### dpibreak-git

Only update when `PKGBUILD` itself changes (e.g., new dependency, new
install target). `pkgver` is auto-generated by `makepkg`.

```bash
git clone ssh://aur@aur.archlinux.org/dpibreak-git.git && cd dpibreak-git
# edit PKGBUILD
docker run --rm -v $(pwd):/home/builder/pkg dpibreak-aur bash -c "cd pkg && makepkg --printsrcinfo > .SRCINFO"
git add PKGBUILD .SRCINFO
git commit
git push
```

### dpibreak (stable release)

Update on every new release:

```bash
scripts/aur-bump.sh vX.Y.Z
```

It updates `pkgver`, `pkgrel` and `sha256sums`, regenerates
`.SRCINFO`, commits, and asks before pushing. Without an argument, it
uses the latest release.
